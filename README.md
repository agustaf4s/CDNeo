# CDNeo

CD・DVD のイメージファイルを、変換したり、仮想ドライブにマウントしたりする Windows 用のソフトです。

> このリポジトリは、配布と不具合報告のためのものです。ソースコードは公開していません。

## 主な特長

- **変換**：BIN/CUE（1ファイル・トラック分割）、ISO、CCD/IMG/SUB に変換します。変換後に出来上がりを読み直して、元のデータと一致するかを自動で確かめます。元のファイルは変えません。
- **多くの形式を読めます**：ISO、CUE＋BIN、CCD/IMG/SUB、MDS＋MDF、MDX、CDI、NRG、CHD。CUE から参照する WAV・FLAC・MP3・OGG・APE にも対応します。
- **CHD**：作成と展開ができます。
- **マウント**：ImgDrive（無料版）を裏で使い、ISO・CUE・CCD はそのまま、それ以外の形式は一時変換して仮想ドライブに入れます。取り出すと、一時ファイルは自動で消えます。
- **マルチセッション・DVD**：CCD・CUE・CDI・MDX のマルチセッションを読み書きします。DVD のイメージは ISO に変換できます。
- **書庫**：ZIP・RAR・7z の中のイメージを、展開せずにそのまま読めます。壊れた RAR の修復もできます。
- **一括処理**：複数のファイルやフォルダを入れて、順に処理できます。1 つ失敗しても残りは続き、最後に結果の一覧が出ます。

使い方は、アプリの［ヘルプ］－［目次］をご覧ください。対応している形式の詳細は、［ヘルプ］－［対応している形式］にあります。

## 動作環境

- Windows 10 以降の 64 ビット版（動作確認は Windows 11）
- .NET のインストールは不要です（同梱しています）。
- マウントには **ImgDrive（無料版）** が必要です（同梱していません。別にインストールしてください）。
- RAR の読み書きには **WinRAR** が必要です（任意。同梱していません）。

## インストール

1. [Releases](https://github.com/agustaf4s/CDNeo/releases) から、最新の `CDNeo-Setup-x.xx.exe` をダウンロードします。
2. 実行して、画面の案内に従います。管理者権限は不要です。既定のインストール先は `%LocalAppData%\Programs\CDNeo` です。
3. スタートメニューの「CDNeo」から起動します。

アンインストールは、Windows の「インストールされているアプリ」から行います。ログやマウントの記録は `%LOCALAPPDATA%\CDNeo` に保存されており、アンインストールしても残ります。不要なら、手で削除してください。

## ご利用にあたって

- **ご自身が所有するディスクのバックアップ・変換の用途**でお使いください。
- コピープロテクトの解除・無効化の機能はありません。サブチャンネルなど、元のイメージにある情報を、形式を変えて写すだけです。DVD の暗号（CSS など）や、パスワード付き MDX の暗号も扱いません。
- 実物で確かめていない形式があります。確かめた範囲は、アプリの［ヘルプ］－［対応している形式］に書いてあります。

## 不具合・要望・感想

アプリの［ヘルプ］から、［不具合を報告］［要望を送る］［感想・使用感を送る］を選ぶと、日本語の案内のあと、GitHub の入力画面が開きます。または [Issues](https://github.com/agustaf4s/CDNeo/issues) から直接お送りください。

- 送るには GitHub のアカウント（無料）が必要です。持っていなければ、ログイン画面の「Create an account」から作れます。
- 画面のボタンなどは英語ですが、入力欄には日本語の見出しがついていて、日本語で書き込めます。書き終えたら、緑のボタン「Submit new issue」を押すと送信されます。
- 不具合は、再現する手順、CDNeo のバージョン、Windows のバージョン、問題のあるイメージの形式を書いていただけると助かります（［不具合を報告］から開くと、バージョンは入力済みです）。
- 要望は、機能の名前より「何をしようとして何に困ったか」を書いていただくと伝わりやすくなります。

CDNeo は、ログなどを自動では送信しません。ログ（`%LOCALAPPDATA%\CDNeo`）にはフォルダ名などの個人的な情報が含まれることがあります。添付する場合は、内容を確認してからにしてください。フォルダ名やファイル名は伏せてください。
